# Futu Portfolio for UlanziDeck

Shows your Futu portfolio worth and gain/loss on an UlanziDeck key, using the same dark ticker layout as the BTC ticker plugin.

## Requirements

- Futu OpenD running locally
- Default connection: `127.0.0.1:11111`

## Display

- Top: currency (HKD / USD / ...)
- Middle: total net assets
- Bottom: gain/loss amount and percent (green up, red down)

Tap the key to refresh immediately.

## Settings

- OpenD host and port
- Real or simulate environment
- Display currency
- Today P&L or total unrealized P&L
- Optional account ID (leave blank for auto: the universal securities account)
- Refresh interval
